# Résumé input notes

`RESUME.md` is the only content brief a new user needs to fill in. It is intentionally structured so an LLM can distinguish verified facts from requested presentation.

Good input produces a stronger site:

- Use exact dates and numbers.
- Separate responsibilities from outcomes.
- Explain what each metric measures.
- Name only clients or employers you may represent publicly.
- Use public contact details only.
- Delete sections that do not apply.
- Put public-ready images and the downloadable résumé in `public/` and list their filenames.

Do not include passwords, API keys, identity documents, confidential figures, home addresses, references’ contact details, or information covered by an NDA.
