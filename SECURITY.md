# Security policy

Do not open a public issue for a vulnerability that could put users at risk. Report it privately to the maintainer using the security contact published on the project’s repository profile.

The base template has no database, authentication, form handler, analytics, or secret environment variables. Fork owners are responsible for the security and privacy impact of services they add.

Never commit passwords, API keys, deployment tokens, private addresses, identity documents, or confidential résumé material.
