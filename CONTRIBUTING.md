# Contributing

Thank you for helping improve the template.

1. Open an issue for substantial behavioral or design changes.
2. Keep pull requests focused and do not include private résumé data or credentials.
3. Preserve the content-first, accessible, responsive design.
4. Run `npm run check` before submitting.
5. Explain the user problem, the change, and how you validated it.

Contributions must be compatible with the MIT License. Do not contribute assets, logos, fonts, or copy unless you have the right to redistribute them.
